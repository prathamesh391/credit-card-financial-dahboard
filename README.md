# Credit Card Analytics — Power BI

## Project Overview
This project contains Power BI reports for exploring credit card transactions and customer-related data.

## Reports
- **Credit Card Transaction Report:** Visual reporting on transaction-related data.
- **Credit Card Customer Report:** Visual reporting on customer-related data.

## Tools
- Power BI
- Power Query
- DAX

## Project Files
The repository contains available report files and dashboard screenshots.

## How to View
View the screenshots in this repository. If the Power BI report files are included, download a `.pbix` file and open it using Power BI Desktop.
